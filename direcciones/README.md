# Direcciones de arte

Una **dirección** es la personalidad visual de la página: cómo se maqueta, qué
manda, cómo se mueve. Elige **una sola** según lo que sea la página. No las
mezcles: una página con dos direcciones se ve indecisa.

| Dirección | Úsala cuando la página… | Sensación |
|---|---|---|
| `01-editorial-sereno` | explica o convence con texto (landing, artículo, "sobre") | revista seria, mucho aire |
| `02-monolito` | tiene una sola idea potente (portada, lanzamiento, hero) | una frase que impone |
| `03-indice` | lista o estructura cosas (documentación, catálogo, precios) | índice de libro, ordenado |
| `04-terminal` | es técnica o de programadores (herramienta, API, dev tool) | consola, oscura, precisa |
| `05-galeria` | muestra imágenes o trabajo (portafolio, productos, casos) | museo, la imagen manda |

Cómo elegir rápido: pregúntate qué es lo único que la persona tiene que captar.
Si es **una frase** → monolito. Si es **entender algo** → editorial. Si es
**encontrar algo en una lista** → índice. Si es **para programadores** →
terminal. Si es **mirar** → galería.

Todas comparten el mismo sistema (`../sistema/tokens.md`): la dirección cambia
la composición, no los materiales.
